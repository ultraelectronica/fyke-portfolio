# Fyke Portfolio

Fyke Simon V. Tonel — solo developer portfolio. A desk of index cards.

Built with Vite, React, TypeScript, Tailwind CSS, and Motion. The landing page
is an interactive stack of tilted index cards — drag to pan and dismiss, each
card is a project or an intro.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Motion (gestures / animations)

## Develop

```bash
pnpm install
pnpm dev
```

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `pnpm dev`        | Start the dev server         |
| `pnpm build`      | Type-check and build for prod|
| `pnpm preview`    | Preview the production build |
| `pnpm typecheck`  | Run the TypeScript compiler  |
